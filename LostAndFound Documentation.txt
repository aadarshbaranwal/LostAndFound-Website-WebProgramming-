📌 Project Overview
The Lost & Found Website is a multi-page static web application designed to help students report lost items and list found belongings within a college campus.
The project focuses on clean UI design, smooth navigation, and user-friendly interaction using HTML, CSS, and basic JavaScript.
This website is built as a Web Programming academic project and demonstrates real-life problem solving through a digital platform.

==>About Us Page (index.html)
Explains:
Purpose of the Lost & Found portal
Motivation behind building the website
Includes two content sections:
About the platform
About the student team

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
==>Lost Items Page (lostitems.html)
Displays items reported as lost by students
Uses a 2-column grid layout
Each card shows:
Item name
Location
Date
Description
Reporter name
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
==>Found Items Page (found.html)
Lists items that have been found or recovered
Card-based layout similar to Lost Items page
Shows:
Lost location
Found location
Recovery status (Recovered / Unrecovered)
Status is visually highlighted using colors
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
==>Report Lost Item Page (reportlost.html)
Form for reporting lost belongings
Collects:
Student name
Class & division
Item details
Category
Last seen location
Date lost
On submission:
Displays a confirmation alert
No backend (static form simulation)
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
==>Report Found Item Page (reportfound.html)
Similar to Report Lost page
Used to report items that someone has found
Collects:
Finder’s details
Item information
Found location
Date found
Displays success alert on submission
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
==>Contact Page (contact.html)
